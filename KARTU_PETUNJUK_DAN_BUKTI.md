> Cetak halaman ini pada kertas tebal (karton/HVS 100gr), gunting sepanjang garis putus-putus, dan masukkan ke dalam 4 amplop berlabel **"BERKAS RAHASIA BUKTI #01 s/d #04"** untuk dibagikan ke tiap kelompok penyelidik.

| - Detergen dan sabun cuci mengandung zat Fosfat yang berfungsi sebagai pupuk buatan.  |
| - Kadar fosfat yang berlebihan menyebabkan 'Ledakan Populasi Tumbuhan Air'            |
|   (Eutrofikasi), seperti eceng gondok liar yang menutupi seluruh permukaan air.       |
| - Saat tumbuhan liar menutupi permukaan, sinar matahari tidak bisa menembus dasar.    |
|   Tumbuhan dasar mati, membusuk, dan bakteri penghancur menyedot habis Oksigen        |
|   Terlarut (DO) di dalam air sampai ikan mati lemas!                                  |
|                                                                                       |
| TANTANGAN PENYELIDIKAN:                                                               |
| "Mengapa busa detergen yang tampak bersih dan harum justru menjadi racun mematikan    |
|  bagi kehidupan hewan air di sungai?"                                                 |

```

+---------------------------------------------------------------------------------------+
| 🔍 KARTU PETUNJUK BUKTI #03: BANGKAI IKAN & LENYAPNYA CAPUNG SUNGAI                   |
+---------------------------------------------------------------------------------------+
| LOKASI PENEMUAN  : Rerumputan di tepian bantaran sungai                               |
| STATUS BUKTI     : Kerusakan Bioindikator Alami Ekosistem                             |
|                                                                                       |
| CATATAN DETEKTIF :                                                                    |
| Petani dan warga yang biasa memancing mengeluhkan bahwa selama 6 bulan terakhir,      |
| mereka tidak pernah lagi melihat capung jarum terbang atau berang-berang berenang.    |
| Hanya tersisa banyak nyamuk dan lalat pembawa kuman penyakit.                         |
|                                                                                       |
| TEMUAN LABORATORIUM SAINS:                                                            |
| - Capung adalah BIOINDIKATOR ALAMI (hewan penanda kebersihan lingkungan).             |
| - Capung betina hanya mau meletakkan telurnya di perairan yang jernih dan kaya oksigen|
| - Anak capung (nimfa) hidup di dasar air selama berbulan-bulan memakan jentik nyamuk. |
| - Ketika air tercemar racun kimia, telur dan nimfa capung langsung mati. Tanpa adanya |
|   nimfa capung, populasi nyamuk demam berdarah melonjak 300%!                         |
|                                                                                       |
| TANTANGAN PENYELIDIKAN:                                                               |
| "Bagaimana lenyapnya hewan sekecil capung bisa memicu wabah penyakit berbahaya bagi   |
|  anak-anak di sekolah kita?"                                                          |
+---------------------------------------------------------------------------------------+
```

| - Air banjir yang tercemar membawa bakteri berbahaya seperti Escherichia coli (E. coli)|

|                                                                                       |
